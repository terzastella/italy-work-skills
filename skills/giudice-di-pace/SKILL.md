# Giudice di Pace (Info Only, Delicate)

Small claims mapped: value limits, no-lawyer cases, how it works — information, lawyer for hard cases.

## When to use

- "giudice di pace", "small claims Italy".
- NEVER for legal strategy (lawyer referral).

## Workflow

1. Scope: value limits (year-stated) + matters covered (small civil, some traffic).
2. No-lawyer cases vs lawyer-advised line, stated plainly.
3. Steps: ricorso filing, fees (contributo unificato bands), hearing basics.
4. Output: path map + costs + referral.

## Rules

- Limits/fees with year; they move — verify live.
- No win predictions, no tactics.
- Every answer ends with referral for non-trivial cases.

## Examples

See `examples/giudice-cases.md`. Scope table in `references/competenze.md`.

## Edge cases

- Above value limit → tribunale track, referral immediately.
- Urgent protection needed → different instruments, flag + referral.
- Counterparty is PA → special rules noted, referral.
