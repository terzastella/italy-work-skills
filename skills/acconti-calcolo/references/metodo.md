# Advance method table (acconti-calcolo)

- Base: prior-year due tax (return line, e.g. LM42 for forfettari).
- Threshold: no advance if ≤52€ (verify year).
- Split: check current AdE rules per tax (IRPEF-style instalments vs single
  sostitutiva advance — do not assert from memory).
- Previsional: allowed if lower income expected; underpayment penalties apply.
- First year: usually no advance. Mixed incomes: per-tax advances, never merged.
