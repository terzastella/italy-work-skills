# Amministratore Condominio

Admin in/out done right: majorities, duties, revoca, judicial path.

## When to use

- "amministratore condominio", "revoke administrator".
- Do not use for account disputes (see `condominio-spese`).

## Workflow

1. Nomina/revoca majorities (ordinary + second call rules, year-stated).
2. Admin duties checklist (see `references/doveri.md`): conto, registro, assicurazione, morosità action.
3. Revoca path: assembly motion → vote → handover (documents + funds).
4. Judicial admin: deadlock/grave reasons → giudice referral, never DIY court.

## Rules

- Majorities with year; rules cited, never approximate counts as law.
- Compensation transparency: preventivi compared, no imposed renewals.
- Small condos (≤8): simplified rules flagged.

## Examples

See `examples/amministratore-cases.md`.

## Edge cases

- Admin holds funds hostage → formal notice + judicial path, urgent tone.
- No admin at all (small) → voluntary vs mandatory line stated.
- Supercondominio admin layers → per-building clarity demanded.
