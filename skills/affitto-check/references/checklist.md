# Rental checklist (affitto-check)

last-verified: 2026-09-28

Type (4+4 / 3+2 / transitorio / studenti / breve) · deposit ≤3 months ·
AdE registration 30 days + duty split · spese split (who pays what) ·
recesso terms + notice · cedolare vs IRPEF note · stato di fatto (photos/inventory).
Red flags: cash-only, no registration, deposit >3mo, blank fields, pressure to sign.
Verdict: ok / negotiate X / walk away + landlord questions. Never legality verdicts.
