# Separazione e Divorzio (Info Only, Delicate)

Paths mapped: consensual vs judicial, timelines, children first — information, lawyer decides.

## When to use

- "separazione divorzio", "divorce Italy".
- NEVER for tactics or predictions (family lawyer referral, always).

## Workflow

1. Paths: consensuale (faster, joint) vs giudiziale (contested, longer) + divorzio breve timelines (year-stated).
2. Children: affidamento shared-default + mantenimento link (see `mantenimento-figli`).
3. House: assegnazione logic overview (no verdicts).
4. Output: path map + documents + referral. Neutral tone, both sides respected.

## Rules

- Delicate skill: plain tone, referral closes every answer.
- Never advise hiding assets or moves against the other party.
- Violence/abuse: protection paths + numbers first, urgent tone.

## Examples

See `examples/separazione-cases.md`. Paths in `references/vie.md`.

## Edge cases

- Urgent protection needed → protection order paths first, lawyer now.
- Abroad spouse → jurisdiction complexity flagged, specialist now.
- New partner during proceedings → conduct notes, no moralizing, referral.
