# Permessi Studio 150 Ore

Study while working, paid: hours, courses, request path.

## When to use

- "permessi studio", "150 ore Italy".
- Do not use for unpaid study leave (see `aspettativa-lavoro`).

## Workflow

1. Eligibility: contract types covered + courses qualifying (diploma/laurea/professional).
2. Hours: 150 over 3 years typical pattern (CCNL cited, never generic).
3. Request: written + enrollment proof + exam certificates after.
4. Output: eligibility + steps + documents.

## Rules

- Hours/conditions per CCNL cited; never generic "150 for all".
- Denied requests: written reasons + appeal paths + referral.
- Exams passed: certificates close the loop, remind it.

See `examples/studio-cases.md`. Eligibility in `references/requisiti.md`.

## Edge cases

- Fixed-term ending: use-it timing math shown plainly.
- Employer "too busy" refusals: rights + referral, documented everything.
- Online universities: qualifying where recognized, verify case.
