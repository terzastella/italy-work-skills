# TFR vs funds (tfr-fondo)

last-verified: 2026-09-28

TFR: yearly accrual, revaluation 1.5% + 75% inflation (year-stated), taxed at exit
separately. Funds: contributions + employer match, separate exit taxation,
anticipazioni rules (casa/salute %). Silence-assent for new hires (opt-out window).
Small firms: Fondo Tesoreria INPS split. TFS (public): different — redirect.
