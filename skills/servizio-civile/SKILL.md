# Servizio Civile

Civil service decoded: calls, allowance, projects that matter.

## When to use

- "servizio civile", "civil service Italy".
- Do not use for military service (different, suspended track — flag it).

## Workflow

1. Calls: yearly bando with windows (year-stated) + age range + requirements.
2. Allowance: monthly amount (year-stated) + project hours.
3. Projects: sectors (assistance, culture, environment, civil protection) + how to choose.
4. Output: eligibility + steps + deadlines.

## Rules

- Windows with year; missed bando = next year, stated plainly.
- Abroad projects: extra allowance + insurance notes where due.
- No placement promises: graduatorie decide.

See `examples/civile-cases.md`. Call anatomy in `references/bandi.md`.

## Edge cases

- Over-age applicant → alternative volunteering paths listed.
- University alongside → compatibility notes, no generic verdicts.
- Dropout mid-service → consequences stated plainly.
