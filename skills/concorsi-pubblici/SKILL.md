# Concorsi Pubblici

Public competitions decoded: bando reading, requirements, tests, rankings.

## When to use

- "concorso pubblico", "public competition Italy".
- Do not use for private hiring.

## Workflow

1. Read the bando: requirements (degree, citizenship, age limits where legal), reservations/quotas.
2. Tests map: preselettiva → written → oral/practical + scores/weights.
3. Application: InPA portal + SPID + fee (year-stated) + deadline (no extensions assumed).
4. Output: eligibility + study plan pointers + calendar.

## Rules

- Requirements from the bando text only, never generic.
- Deadlines absolute: late = out, stated bluntly.
- No "how to pass" guarantees: preparation method, not promises.

## Examples

See `examples/concorsi-cases.md`. Bando anatomy in `references/anatomia.md`.

## Edge cases

- Title evaluation (titoli) → document every point-claiming title.
- Reserved quotas (disability, military) → eligibility + proof paths.
- Excluded after applying → ricorso paths briefly + specialist referral.
