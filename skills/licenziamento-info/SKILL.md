# Licenziamento (Info Only, Delicate)

Dismissals mapped: types, challenge terms, first steps — information, union/lawyer now.

## When to use

- "licenziamento", "fired Italy", "dismissal challenge".
- NEVER for legal strategy: types + terms + referral only.

## Workflow

1. Type: giusta causa (no notice) · giustificato motivo oggettivo/soggettivo (notice) ·
   collettivo (procedure) · discriminatory (null, special path).
2. Terms: 60-day challenge + 270-day follow-up (year-stated) — the killer deadline, stated first.
3. First steps: written everything kept, patronato/union/lawyer immediately, NASpI path parallel.
4. Output: type map + deadlines + referrals. No win predictions.

## Rules

- Delicate skill: every answer ends with professional referral.
- Never predict outcomes or suggest tactics ("say X to win").
- Discriminatory dismissal suspicion → specialist immediately, extra care in tone.

## Edge cases

- Verbal dismissal → written-proof urgency + witness note, referral now.
- Dimissioni forced ("resign or fired") → coercion flag + referral, never sign under pressure advice beyond basics.
- Trial/d fixed-term end → different track (see periodo-prova), do not mix.
