# xlsx-budget-it cases

## January budget with data

Input: salary $2000, rent $800, groceries $350, transport $120.

Output: `budget-2026-01.xlsx` file (3 sheets, formulas) + summary:
```text
Income: $2000 | Expenses: $1270 | Balance: $730
Housing 63% | Food 28% | Transport 9%
```

## No data

Output: empty template with 2 `[example]` rows + `Delete the example rows and enter your items.`
