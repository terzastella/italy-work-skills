# Pensione Guida (Info Only)

Retirement mapped: old-age, early, quota paths — information, patronato computes.

## When to use

- "pensione", "retirement Italy", "quota", "vecchiaia".
- NEVER for personal pension math or applications (patronato referral).

## Workflow

1. Profile: age, contribution years, schemes (lavoratori dipendenti/autonomi/gestioni).
2. Paths: vecchiaia (age + minimum years) · anticipata (years-based) · quota schemes (year-stated, temporary by nature).
3. Estratto conto check first: missing weeks are the classic surprise.
4. Output: likely paths + documents + patronato referral. No date promises.

## Rules

- Requirements with year; quota schemes expire/change — verify current.
- Never compute a pension amount here.
- "Riforma coming" rumors: only enacted law cited, never drafts as facts.

## Examples

See `examples/pensione-cases.md`. Path map in `references/percorsi.md`.

## Edge cases

- Mixed schemes (cumulo) → free cumulo overview + patronato (complex).
- Abroad years → totalization agreements flagged, specialist referral.
- Early exit pressure → quota vs anticipata trade-offs listed, no push.
