# Pignoramento Conto (Info Only, Urgent-Aware)

Seized accounts decoded: what is protected, opposition terms, urgent referral.

## When to use

- "pignoramento conto", "account seizure Italy".
- NEVER for strategy against creditors (lawyer referral, always).

## Workflow

1. Title check: what order backs the seizure (decreto/cartella/sentenza).
2. Exempt minimums (year-stated): salary/pension portions protected — stated first.
3. Opposition terms + who (giudice dell'esecuzione) + documents.
4. Output: situation map + urgent steps + referral. No outcome promises.

## Rules

- Urgent tone where money is blocked; referral first, not last.
- Never advise hiding/moving funds: stated as harmful, plainly.
- Terms with year; missing them is fatal — stated first.

## Examples

See `examples/pignoramento-cases.md`. Exemptions in `references/minimi.md`.

## Edge cases

- Salary already garnished at source → double-hit check + referral.
- Joint account → non-debtor share protection flagged.
- Irregular/fake title → opposition grounds + lawyer now.
