# colf-badanti cases

## Good: badante convivente hiring

Input: non-self-sufficient elder, convivente badante [sample data].

Output: level match + pay math (minimums year-stated) + contributions path (F24 quarterly)
+ permits note if non-EU + `CCNL tables cited, never generic pay figures.`

Input: "quanto si paga una colf?" with no level/hours [sample data].

Output: no figure. `Levels and minimums with year + CCNL cited — profile first (mansioni, hours, convivente?), numbers after.`

## Bad: DIY quotas

Input: non-EU hiring "without paperwork" [sample data].

Output: `Hiring-decreto flows + referral, never DIY on quotas. Irregular work risks stated plainly for both sides.`
