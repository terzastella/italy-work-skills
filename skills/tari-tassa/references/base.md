# TARI base logic (tari-tassa)

Base: sqm × occupants/use class → fixed + variable shares per municipal tariff (year-stated).
Reductions: single occupant, seasonal use, composting, out-of-town — each requested
via forms/deadlines, never automatic. Business: separate classes/rates.
Instalments per comune calendar (F24/pagoPA). Verify comune regolamento yearly.
