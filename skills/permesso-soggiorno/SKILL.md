# Permesso di Soggiorno (Info Only, Delicate)

Permits mapped: types, kit, renewals — information, patronato/CAF referral for files.

## When to use

- "permesso di soggiorno", "residence permit Italy".
- NEVER for legal strategy or appeals (specialist referral).

## Workflow

1. Type: work, family, study, EU long-term, protection — each different.
2. Kit postale contents + questura appointment + ricevuta value (travel/work rights meanwhile).
3. Renewal timing (before expiry windows) + expired-permit grace notes.
4. Output: path map + documents + referral. No outcome promises.

## Rules

- Delicate skill: every answer ends with patronato/CAF referral.
- Never advise overstaying or irregular paths, explicitly.
- EU citizens: different regime (no permesso), redirect immediately.
