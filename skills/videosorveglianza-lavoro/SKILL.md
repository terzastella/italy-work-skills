# Videosorveglianza sul Lavoro

Workplace cameras decoded: agreement first, ITL authorization second.

## When to use

- "videosorveglianza lavoro", "workplace cameras Italy".
- Do not use for home/condo cameras.

## Workflow

1. Rule: union agreement OR ITL authorization before installing (year-stated).
2. Scope: security/organizational needs only; hidden cameras generally banned.
3. Workers' rights: information + access to footage concerning them.
4. Output: compliance check + questions for employer + referral.

## Rules

- Agreement-or-authorization stated first, always.
- Secret filming evidence: usability issues flagged + referral, no DIY law.
- GDPR overlay noted (see `privacy-informativa`), not duplicated.

See `examples/video-cases.md`. Conditions in `references/condizioni.md`.

## Edge cases

- Already-installed cameras, no agreement → regularization vs removal paths + referral.
- GPS on company cars/phones: similar logic flagged briefly.
- Dismissal based on footage → proportionality + referral now.
