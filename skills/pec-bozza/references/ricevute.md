# PEC receipts — what to keep (pec-bozza)

- **Accettazione** (acceptance): your provider took the message. Proves sending time.
- **Consegna** (delivery): recipient mailbox got it. Proves delivery; legal value = PEC-to-PEC + BOTH receipts.
- Keep both as files + print PDF for disputes. Retention: same as the matter (years for contracts/tax).
- PEC→ordinary email: NO certified value. Ordinary→PEC: NO certified value. Say it every time.
- If no delivery receipt in 24h → check address, resend, keep the anomaly note.
- AgID lists certified providers; anyone can get a PEC mailbox — no sender mailbox = get one first.
- Attachments ride inside the certified envelope: name them in the body so receipts cover them.
- Urgent + dispute coming: lawyer before sending; draft stays neutral and factual regardless.
