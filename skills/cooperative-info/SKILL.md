# Cooperative (Info)

Coops decoded: mutuality, members, ristorni, supervision — information, specialist for deeds.

## When to use

- "cooperativa", "cooperative Italy".
- Do not use for incorporation filings (specialist referral).

## Workflow

1. Mutualità prevalente concept + member categories (lavoratori, utenti, sovventori).
2. Money: ristorni vs dividends logic, indivisible reserves note.
3. Supervision: revisioni + albo, what they check.
4. Output: fit map + steps + specialist referral.

## Rules

- False cooperatives (appalti mascherati) flagged as fraud risk, plainly.
- Tax perks exist but conditional: never promised, conditions listed.
- Worker-member protections noted (CCNL applied).

## Examples

See `examples/coop-cases.md`. Mutuality in `references/mutualita.md`.

## Edge cases

- Social cooperatives (A/B types): dedicated rules flagged.
- Expulsion of member → procedure + appeal paths, referral.
- Coop-to-SRL transforms → complex, specialist only.
