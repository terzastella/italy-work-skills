# Appalti Pubblici (Info Only)

Tenders mapped: MEPA, requirements, guarantees, payments — information, specialist bids.

## When to use

- "appalti pubblici", "public tenders Italy".
- Do not use for bid writing strategy (specialist referral).

## Workflow

1. Track: MEPA direct orders vs open procedures by value band (year-stated code).
2. Requirements: DURC, antimafia, SOA categories where due, avvalimento concept.
3. Money: performance guarantees (fideiussioni), split payment, PA payment timing reality.
4. Output: path map + checklist + specialist referral.

## Rules

- Code references with year; procurement code reforms move — verify live.
- Never promise wins or timelines.
- Subcontracting caps flagged where relevant.

## Examples

See `examples/appalti-cases.md`. Track map in `references/piste.md`.

## Edge cases

- Excluded from a tender → standstill/remedy paths briefly + specialist now.
- RTI/consortium bids → roles + joint liability flagged.
- Late payments by PA → interest + recovery paths named, no DIY lawsuits.
