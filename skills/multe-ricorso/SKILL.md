# Multe Ricorso (Info Only, Delicate)

Fine appeals mapped: prefetto vs giudice di pace, terms, trade-offs — information, no tactics.

## When to use

- "multa ricorso", "traffic fine appeal Italy".
- NEVER for legal strategy or guaranteed outcomes.

## Workflow

1. Options: discounted payment (ridotta, terms) vs prefetto appeal (60 days) vs giudice di pace (30 days) — year-stated.
2. Trade-offs: costs, timelines, points freeze notes, loss consequences.
3. Formal defects checklist (see `references/vizi.md`): what to look for, described not judged.
4. Output: options table + chosen path steps + referral for hard cases.

## Rules

- Delicate skill: plain procedure, zero tactics, referral for disputes.
- Terms with year; missing them kills everything — stated first.
- Never "you will win" predictions.

## Examples

See `examples/multe-cases.md`.

## Edge cases

- Notification defects → describe checks, professional evaluates.
- Company car → driver declaration duty first, then appeal clock.
- Already paid → appeal usually over, state it (rare exceptions flagged).
