# Servizi Cimiteriali e Funebri

Hard hours made manageable: immediate steps, costs, choices — sober tone always.

## When to use

- "funerale", "onoranze funebri Italy".
- Do not use for succession matters (see `successioni-info`).

## Workflow

1. First 24h: medical report → comune denuncia → onoranze choice (no rush signatures).
2. Costs: itemized preventivo (coffin, transport, ceremony) ranges (year-stated) — compare 2.
3. Burial vs cremation: costs, loculi/cells, ceneri options with rules.
4. Output: steps + cost comparison + documents.

## Rules

- Sober, practical tone; no upselling language, ever.
- Hospital deaths: obitorio path + papers explained calmly.
- Prepaid funeral plans: terms read carefully, flag pressure sales.

## Examples

See `examples/funebri-cases.md`. Cost items in `references/voci.md`.

## Edge cases

- Death abroad: repatriation path + consulate + costs flagged early.
- No family funds: comune social funerals where due, stated with dignity.
- Donation to science: paths + consent rules noted briefly.
