# Somministrazione (Agency Work)

Interinale decoded: agency + user, parity pay, mission rules.

## When to use

- "somministrazione", "interinale", "agency work Italy".
- Do not use for direct fixed-term contracts.

## Workflow

1. Triangle: agency (employer) + user company (mission) + worker rights.
2. Parity: same pay as user employees at level (CCNL applied) — the core rule.
3. Missions: duration, extensions, stop-and-go limits (year-stated).
4. Output: situation check + questions for agency + union referral if violated.

## Rules

- Parity principle stated first; gaps = red flags.
- Mission limits with year; extensions beyond = stabilized-or-stop logic.
- No "agency vs direct" verdicts: facts + referral.

## Examples

See `examples/somministrazione-cases.md`. Triangle map in `references/triangolo.md`.

## Edge cases

- Endless extensions → stabilization paths flagged + referral.
- Pay below user's level peers → parity claim route, union now.
- Staff leasing (permanent) → different track, do not mix.
