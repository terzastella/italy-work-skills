# Trasferimento di Sede

Transfers decoded: proven reasons, allowances, refusal paths.

## When to use

- "trasferimento sede", "work transfer Italy".
- Do not use for dismissals disguised as transfers (flag + referral, see below).

## Workflow

1. Legitimacy: technical/organizational/productive reasons required — stated.
2. Terms: notice, transfer allowance (indennità), moving costs, timing.
3. Refusal: legitimate reasons (family/health) + challenge paths + union referral.
4. Output: situation check + questions for employer + referral.

## Rules

- Punitive transfers (post-complaint) flagged as retaliation patterns + referral.
- Allowance/timing per CCNL cited, never generic.
- No "accept/refuse" verdicts: facts + referral.

## Examples

See `examples/trasferimento-cases.md`. Rules in `references/regole.md`.

## Edge cases

- Transfer abroad → different regime + protections flagged, referral.
- Disabled workers/caregivers (L.104) → special protections, referral now.
- Smart-worker ordered back full-time → change-of-terms flag + referral.
