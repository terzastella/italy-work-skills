# Officina Diritti

Repairs without surprises: written quotes, old parts back, warranty on work.

## When to use

- "officina", "mechanic rights Italy", "riparazione auto".
- Do not use for DIY repair advice.

## Workflow

1. Quote: written, itemized (lavoro/ricambi/IVA) before authorizing.
2. Old parts returned on request — ask upfront, stated as right.
3. Repair warranty: legal guarantee on the work performed.
4. Disputes: written contest + second-opinion quote + conciliazione paths.

## Rules

- No authorization = no payment for extras: stated bluntly.
- Estimates vs preventivi vincolanti: difference explained.
- No mechanic endorsement.

## Examples

See `examples/officina-cases.md`. Quote anatomy in `references/preventivo.md`.

## Edge cases

- Car held hostage → diritto di ritenzione limits + referral, urgent tone.
- Dealer vs independent: warranty-network constraints explained neutrally.
- Post-accident repairs: insurer expert (perito) interplay flagged.
