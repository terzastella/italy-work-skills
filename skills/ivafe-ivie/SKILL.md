# IVAFE e IVIE

Foreign holdings taxed: accounts, properties, RW monitoring — information, commercialista computes.

## When to use

- "IVAFE", "IVIE", "foreign assets tax Italy".
- Do not use for full return filing.

## Workflow

1. IVAFE (financial abroad) vs IVIE (property abroad): bases + rates (year-stated).
2. RW section always alongside: monitoring duty even when no tax due.
3. Deductions/credits for foreign taxes paid (double-tax treaties overview).
4. Output: situation map + documents + referral.

## Rules

- Rates/thresholds with year; verify live.
- Crypto abroad: RW + fiscal track (see `criptovalute-fisco`), linked not merged.
- Never advise hiding foreign assets: penalties severe, stated plainly.

## Examples

See `examples/ivafe-cases.md`. Rate table in `references/aliquote.md`.

## Edge cases

- AIRE vs resident: different duties, flag + verify case.
- Inherited foreign assets: declaration from day one, referral.
- Joint accounts abroad: per-holder logic explained generally.
