# Carta Prepagata

Prepaids decoded: with/without IBAN, caps, kids, travel use.

## When to use

- "carta prepagata", "prepaid card Italy".
- Do not use for credit advice.

## Workflow

1. Types: plain prepaid vs IBAN-associated (bonifici in/out, salary credit possible).
2. Caps: load/spend monthly limits + fees (issue, reload, ATM) — year-stated ranges.
3. Kids: parental controls + age rules where due.
4. Travel: accepted where circuits run; holds (hotel/car) need credit, flagged.
5. Output: needs-matched comparison points.

## Rules

- Fees with year; promos expire — verify live.
- No product endorsement.
- Lost/stolen: block numbers + timelines stressed first.

## Examples

See `examples/prepagata-cases.md`. Cap logic in `references/limiti.md`.

## Edge cases

- Salary on prepaid-IBAN: possible where IBAN present, stated plainly.
- Abroad reliance only: backup card advised (acceptance gaps exist).
- Expired funds: reclaim paths + timelines noted.
