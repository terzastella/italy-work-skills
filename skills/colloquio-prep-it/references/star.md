# STAR method (colloquio-prep-it)

last-verified: 2026-09-28

Situation (2 lines) → Task (your responsibility) → Action (what YOU did, verbs) →
Result (number if any). Prepare 3 stories: success, conflict, mistake+fix.
Answers 60-90 seconds spoken. End each with the lesson, not the brag.
Questions to ask them: role reality, team, growth, red flags to listen for.
