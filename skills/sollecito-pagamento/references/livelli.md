# Reminder levels (sollecito-pagamento)

- **L1 polite (<30d)**: "gentle reminder", facts, new 7-day deadline, offer to resend invoice.
- **L2 firm (30-60d)**: prior reminder cited, shorter deadline, consequences preview (late interest if due).
- **L3 formal (60d+)**: registered tone, full history, interest quantified (rate from user/contract),
  next step stated (e.g. handover). Still no threats.
- Each level in Italian + 2-line English summary. Facts: number, date, amount every time.
