# Tappe (percorso-casa-compravendita)

last-verified: 2026-09-28

## 1. Budget → mutuo-tassi + xlsx-budget-it

Input: income + savings. Output: ceiling instalment + budget file. Never stretch ratios silently.

## 2. Purchase → compravendita-casa

Proposta → preliminare (caparra types) → rogito. Info-only clauses.

## 3. Costs → spese-notarili + prima-casa-agevolazioni

Input: price + agevolazione status. Output: imposte + onorario estimate.

## 4. IMU → imu-calcolo (+ script)

Seconda casa/luxury? Run `imu.py` with comune rate input. Main home: exempt stated.

## 5. Running → tari-tassa + utenze-voltura

TARI + meter moves + first-year cost summary. Close: notary + accountant check.
