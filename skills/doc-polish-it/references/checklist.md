# doc-polish-it checklist

last-verified: 2026-09-28

## Structure
- [ ] Single H1 at the top
- [ ] H2/H3 in order, no H1->H3 jumps
- [ ] 2-3 line intro: what + for whom
- [ ] Sections: Install / Usage / Examples / License (if applicable)

## Style
- [ ] Sentences <25 words, active voice
- [ ] Imperative for instructions ("Run", not "One should run")
- [ ] No emoji, no superlatives ("incredible", "super-powerful")
- [ ] Consistent you-form (default "you")

## Technical
- [ ] Every code block with language
- [ ] Paths in backticks, commands copy-pasteable
- [ ] Descriptive lines max ~72 chars where possible
- [ ] No secrets/tokens in text
