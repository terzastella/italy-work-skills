# NASpI gates (naspi-guida)

last-verified: 2026-09-28

## Entry gates (all must pass, stated pass/fail from user data)

- Involuntary termination: dismissal, fixed-term expiry, consensual termination
  with legal conditions met. Voluntary quit = NO (just-cause exception only,
  evidence-heavy, lawyer referral immediately).
- Contribution weeks minimum in the reference period (verify current INPS figure + year).
- Employment type covered (employees; separate tracks for parasubordinati/committenti flagged).

## Amount and duration (method, INPS computes)

- Reference salary from contribution records → percentage brackets → monthly cap
  (current INPS circular + year cited, never from memory).
- Duration = half the contribution weeks of the last 4 years (verify current rule + year).

## Application and duties

- INPS online (SPID/CIE) or patronato; deadline runs from termination — file promptly.
- While receiving: DID registration, servizio/personalized pact, suitable job offers
  regime, communications duty (new work, address, availability).
- INPS decides on records: never promise approval, never invent timelines.
