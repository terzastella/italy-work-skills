# While receiving NASpI (naspi-guida)

The benefit has strings attached. All of them, in order.

## DID + pact

Dichiarazione di immediata disponibilità + personalized servizio/pact with the
employment center. Missed appointments have consequences — stated plainly.

## Suitable offers (congrua)

Refusal rules for job offers deemed suitable (distance, pay, profile —
year-stated criteria). Count of refusals before consequences, stated.

## Communications duty

New work (even short/occasional), address changes, availability changes:
communicate promptly or face suspension/revocation. Work-while-on-NASpI
compatibility: some earnings allowed with rules — explained simply, never
as an invitation to hide work.

## End of benefit

Exhaustion → ordinary job-search rules resume. Re-application needs new
contribution weeks — the clock restarts, stated plainly.
