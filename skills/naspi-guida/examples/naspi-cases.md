# naspi-guida cases

## Good: fixed-term expiry

Input: 12-month contract ended, contributions ok [sample data].

Output: gates pass/fail table (involuntary end = pass) + documents + INPS/patronato route +
`first payment timing per INPS rules (year-stated). Never promise approval.`

## Good: seasonal worker chain

Input: stagionale, 4 summer seasons, same employer [sample data].

Output: expiry path per season + contribution weeks count help + NASpI between seasons (see `stagionali-turismo`) + file promptly each time.

## Bad: voluntary quit (blocked)

Input: "I quit, get me NASpI".

Output: `Voluntary resignation excludes NASpI. Exceptions: just cause (lawyer now) — otherwise no benefit. I do not build false hopes.`

## Bad: amount invented

Input: "how much will I get?" with no salary records [sample data].

Output: no figure. `Brackets and caps live in INPS circulars — method shown, amounts only on your records with circular year cited.`
