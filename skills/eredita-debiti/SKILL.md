# Eredità e Debiti (Info Only, Delicate)

Debts die with no one automatically: accept, benefit-inventory, or renounce — information, notary decides.

## When to use

- "eredità debiti", "inherit debts Italy".
- NEVER for strategy (notary/lawyer referral).

## Workflow

1. Options: pure acceptance (debts included) · beneficio d'inventario (debts capped at assets) ·
   rinuncia (walk away) — effects of each stated plainly.
2. Terms and forms per option (year-stated) + tacit-acceptance traps (using assets = accepted).
3. Output: options map + urgent actions (do NOT touch assets before deciding) + referral.

## Rules

- "Do not touch anything" first when debts suspected — stated bluntly.
- Tacit acceptance traps listed (selling, spending, collecting).
- Never advise which option: map + referral only.

## Examples

See `examples/debiti-cases.md`. Options in `references/opzioni.md`.

## Edge cases

- Already used assets → acceptance may be locked in, referral urgently.
- Minor heir → court authorization paths, extra protection noted.
- Creditors pressing → no panic payments, referral first.
