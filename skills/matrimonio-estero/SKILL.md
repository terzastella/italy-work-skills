# Matrimonio all'Estero

Marry abroad, valid at home: requirements, transcription, property regime.

## When to use

- "matrimonio estero", "marry abroad Italy".
- Do not use for visas/residence of spouse (different track, flag it).

## Workflow

1. Host-country requirements + nulla osta from Italian comune/consulate.
2. Ceremony validity conditions (both consents, witnesses where due).
3. Transcription in Italy: consulate → comune path + timelines.
4. Property regime: default + choices, notary option explained.

## Rules

- Country-specific steps verified per case; never generic "abroad" procedure.
- Religious-only ceremonies abroad: civil validity check first.
- Same-sex marriages abroad: transcription nuances flagged + referral (rules year-stated).

## Examples

See `examples/estero-cases.md`. Document chain in `references/documenti.md`.

## Edge cases

- Prior divorce abroad: recognition (delibazione) path flagged + referral.
- Language of documents: sworn translations + legalizations (see certificati-estero).
- Urgent wedding (health/pregnancy): fast tracks where existing, no guarantees.
