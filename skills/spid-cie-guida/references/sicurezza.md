# SPID/CIE security rules

- NEVER ask for or handle passwords, OTPs, PINs, PUKs. If offered: refuse + explain why.
- Recovery only via official provider helpdesk (linked, verify-date).
- Phishing: check sender domain, never click links in unexpected "SPID" messages.
- Minors/represented persons: dedicated paths (parents, guardians, delegations).
- Lost CIE: PUK for unlock, police report if stolen, then reissue path.
