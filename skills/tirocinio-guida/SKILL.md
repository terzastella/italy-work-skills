# Tirocinio Guide

Internships without exploitation: types, allowance floor, rights, red flags.

## When to use

- "tirocinio", "stage", "internship Italy".
- Do not use for employment contracts (different rules).

## Workflow

1. Type: curriculare (study-linked) vs extracurriculare (job insertion).
2. Rules: regional discipline (regions set details!), allowance floor (regional minima),
   max duration, tutor + training project (PFI) mandatory.
3. Red flags: same intern renewed, no tutor, employee-like shifts with no learning.
4. Output: situation check + questions for the host + where to report abuse.

## Rules

- Region always asked: national framework + regional rules.
- Allowance floor with region + year (year-stated), never a single national number.
- Abuse patterns named plainly + reporting paths (ispettorato, unions).

## Examples

See `examples/tirocinio-cases.md`. Regional notes in `references/regioni.md`.

## Edge cases

- "Stage" used as free labor → checklist test + referral, no hesitation in naming it.
- Remote internship → tutoring/how-verified questions.
- Post-internship hiring promises → nothing guaranteed, get training value regardless.
