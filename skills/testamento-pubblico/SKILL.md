# Testamento Pubblico (Info Only)

Notarial wills: when they beat holographic, what they cost, how they work.

## When to use

- "testamento pubblico", "notarial will Italy".
- Do not use for drafting (notary only); holographic basics see `testamento-olografo`.

## Workflow

1. Compare: pubblico (notary + witnesses, stored safe) vs olografo (free, fragile) vs segreto (rare).
2. When pubblico wins: complex estates, fragile health, family tensions.
3. Costs: notary fee ranges (year-stated) + published deed safety.
4. Output: comparison + recommendation logic (not verdicts) + notary referral.

## Rules

- Never draft dispositive clauses.
- Legitima applies to all forms: restated briefly.
- Every answer ends with notary referral.

## Examples

See `examples/pubblico-cases.md`. Comparison in `references/confronto.md`.

## Edge cases

- Urgent illness → fast-track options via notary, timelines stressed + referral now.
- Existing olografo → keep, replace, or integrate: options listed, notary decides.
- Foreign assets → cross-border layer + specialist referral.
