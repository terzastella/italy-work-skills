# RT vs software vs special flows

| Case | Tool | Note |
|------|------|------|
| Shop/bar/retail | Registratore telematico | daily transmission |
| No fixed premises | Software solution | AdE-approved flow |
| Vending no-comms | Dedicated vending flow | not RT rules |
| Vending with comms | Dedicated vending flow | different timing |
| Fuel | Dedicated fuel flow | daily litres-based |
| Services to consumers | RT or invoice | customer chooses invoice |

When in doubt: activity + ATECO → accountant confirms the right flow.
