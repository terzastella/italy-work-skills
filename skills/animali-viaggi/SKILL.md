# Animali in Viaggio

Pets across borders: microchip, vaccines, pet passport, airline rules.

## When to use

- "animali viaggi", "pet travel Italy", "passaporto animali".
- Do not use for veterinary advice.

## Workflow

1. Species first: dogs/cats/ferrets (EU pet rules) vs others (CITES/vet referral).
2. EU travel: microchip + anti-rabies (21-day wait after first shot) + EU pet passport.
3. Airline/train rules: carrier, hold vs cabin, booking steps.
4. Output: documents checklist + timeline (start weeks ahead).

## Rules

- 21-day post-vaccine wait stated (classic trip-killer).
- Banned breeds/destinations flagged (UK quirks, airline bans).
- Commercial movements (breeders): different rules, referral.

## Examples

See `examples/animali-cases.md`. Document list in `references/documenti.md`.

## Edge cases

- Non-EU destination → country rules vary widely, official source + vet, start early.
- Expired vaccine → revaccinate + wait again, no shortcuts.
- Assistance animals → airline-specific rights, flag + verify.
