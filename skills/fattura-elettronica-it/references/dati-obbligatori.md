# Mandatory invoice data (art. 21 DPR 633/72, summary)

last-verified: 2026-09-28

Seller: business name, VAT ID. Buyer: VAT ID or tax code (as communicated).
Body: date, progressive number, item description, quantity, price, taxable base,
VAT rate + tax (or Natura code when no VAT), total.
Recipient: 7-char SdI code · `0000000` + PEC for consumers · PA code (IPA).
Simplified: only ≤100€ total. Drafting aid — verify with accountant.
