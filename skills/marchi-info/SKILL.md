# Marchi e Brevetti (Info Only)

IP basics: trademark vs patent vs design, where to file, what it costs.

## When to use

- "marchio", "brevetto", "trademark Italy".
- NEVER for filing strategy or disputes (IP attorney referral).

## Workflow

1. Distinguish: marchio (brand) vs brevetto (invention) vs design vs copyright.
2. Paths: UIBM (Italy), EUIPO (EU trademark/design), EPO (patent) — offices + Nice classes concept.
3. Costs/timelines indicative with year; prior-art search strongly advised.
4. Output: path map + checklist + attorney referral.

## Rules

- No clearance searches here: similarity = attorney's job.
- Never promise registrability.
- Domain names ≠ trademarks: stated plainly.

## Examples

See `examples/marchi-cases.md`. Office map in `references/uffici.md`.

## Edge cases

- Already using an unregistered brand → risks + filing urgency, no panic.
- Copycat found → evidence preservation + attorney now, no DIY letters.
- Software: copyright + (rarely) patent angles, specialist referral.
