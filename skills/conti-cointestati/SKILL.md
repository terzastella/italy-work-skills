# Conti Cointestati

Joint accounts decoded: disgiunta vs congiunta, shares, death blocks.

## When to use

- "conto cointestato", "joint account Italy".
- Do not use for succession computation (see successioni-info).

## Workflow

1. Signature: disgiunta (either operates) vs congiunta (both needed).
2. Death: 50% presumption + succession on share; account partially blocked — stated first.
3. Separation/divorce: contribution proof decides splits, presumptions rebuttable (no verdicts).
4. Output: situation map + documents + notary/lawyer referral for disputes.

## Rules

- 50/50 is a presumption, not destiny: proof decides, stated plainly.
- Never advise emptying joint accounts in disputes.
- Seizure of one holder: other share protected path flagged + referral (rules year-stated).

## Examples

See `examples/cointestati-cases.md`. Signature logic in `references/firme.md`.

## Edge cases

- Elderly parent + child helper → mandate vs cointestazione trade-offs explained.
- Non-married partners: same rules, extra proof care advised.
- One holder drains all → civil/criminal angles flagged + referral now.
