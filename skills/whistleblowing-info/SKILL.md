# Whistleblowing (Info)

Report wrongdoing protected: channels, confidentiality, anti-retaliation.

## When to use

- "whistleblowing Italy".
- Do not use for the report content strategy (specialist referral).

## Workflow

1. Channels order: internal → ANAC/external → public disclosure (conditions differ).
2. Protections: confidentiality + retaliation ban + support measures overview.
3. Company duty: internal channel where mandatory (size thresholds, year-stated).
4. Output: path map + documents + referral.

## Rules

- False reports in bad faith excluded from protection: stated plainly.
- Anonymous vs confidential distinction explained.
- Retaliation suffered: document + referral now, urgent tone.

## Examples

See `examples/whistleblowing-cases.md`. Channel order in `references/canali.md`.

## Edge cases

- Small firm, no channel → external ANAC path directly, explained.
- Manager is the problem → skip-level paths + protections stressed.
- Already retaliated → evidence + referral now, no checklists first.
