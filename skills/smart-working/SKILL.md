# Smart Working (Lavoro Agile)

Agile work with rules: individual agreement, disconnection, tools, injuries.

## When to use

- "smart working", "lavoro agile Italy".
- Do not use for generic remote-work tips.

## Workflow

1. Agreement: individual written agreement mandatory (content list in `references/accordo.md`).
2. Disconnection windows + overtime rules in agile mode.
3. Tools/expenses: who provides, buoni pasto treatment (flag, rules vary).
4. INAIL coverage note for agile injuries. Close with CCNL specifics referral.

## Rules

- No agreement = red flag: state it.
- Buoni pasto in agile: debated area — present positions, no verdict (rules year-stated).
- Fragile workers/agile priority rights mentioned where relevant.

## Examples

See `examples/smart-cases.md`.

## Edge cases

- Employer revokes unilaterally → agreement terms decide, referral.
- Full-remote imposed by contract change → substantial-change flag + referral.
- Public sector agile → separate rules track, do not generalize private ones.
