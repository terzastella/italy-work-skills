# Dimissioni (Italy) — Procedure Info

Resigning correctly: online procedure, notice (preavviso), what to check first. Information only.

## When to use

- "dimissioni", "resign Italy", "notice period", "preavviso".
- Do not use for legal advice: procedure info + union/lawyer referral.

## Workflow

1. Explain the online procedure (INL portal, SPID/CIE, assisted subjects: patronati/unions).
2. Notice: length comes from the applicable CCNL + seniority — look up, never guess.
3. Checklist before clicking: NASpI implications, TFR, unused holidays, non-compete if any.
4. Close with: verify CCNL + talk to union/consultant for your case.

## Rules

- Never state a notice length without naming the CCNL + source.
- No "just resign" pushes: consequences first (NASpI loss on voluntary quit).
- Dates computed from user data only.

## Examples

See `examples/dimissioni-cases.md`. Official sources in `references/fonti.md`.

## Edge cases

- Just cause (giusta causa) → different path, lawyer immediately, no DIY.
- Trial period → usually no notice, verify contract clause.
- Fixed-term early exit → penalties possible, flag + professional referral.
