# busta-paga-leggi cases

## Standard month check

Input: base €1.800, straordinari €150, detrazioni applied, netto €1.620 [sample data].

Output: line walk (base+overtime−INPS−IRPEF+detrazioni=net recomputed) +
`TFR accruing separately` + `cross-check with CU at year end.`
Mismatch example: recomputed €1.600 vs stated €1.620 → `€20 gap: ask payroll,
possible conguaglio — not an accusation.`
