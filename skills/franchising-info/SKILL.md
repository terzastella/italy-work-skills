# Franchising (Info)

Affiliation decoded: disclosure duties, fees, royalties, exit — before signing anything.

## When to use

- "franchising", "franchise Italy".
- Do not use for contract signing (lawyer referral for the deed).

## Workflow

1. Disclosure: franchisor must deliver pre-contract info pack in time (year-stated rules).
2. Math: entry fee + royalties + marketing + mandatory supplies → true yearly cost.
3. Exit: duration, renewal, non-compete, what stays with you.
4. Output: offer check + questions for franchisor + referral.

## Rules

- Missing disclosure = red flag #1, stated bluntly.
- Earnings promises ("guadagni X") tested against data, never believed.
- Territory exclusivity verified in writing, not in slides.

## Examples

See `examples/franchising-cases.md`. Checklist in `references/checklist.md`.

## Edge cases

- Pressure to sign fast → slow-down advice + disclosure clock stated.
- Failed outlets of the chain → ask numbers, verify independently.
- Home-based micro-franchise → same rules apply, no "too small" exception.
