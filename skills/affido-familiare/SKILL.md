# Affido Familiare (Info Only, Delicate)

Foster care mapped: consensual vs judicial, allowances, timeframes.

## When to use

- "affido familiare", "foster care Italy".
- NEVER for strategy or predictions (tribunale minorenni + services decide).

## Workflow

1. Types: consensuale (services agreement) vs giudiziale (court ordered).
2. Requirements overview: suitability assessment by services (no self-certification of fitness).
3. Allowances: monthly contribution (year-stated) + expense reimbursements.
4. Output: path map + services contact logic. No promises, ever.

## Rules

- Delicate skill: plain tone, referral closes every answer.
- Never predict suitability or timelines.
- Child-first framing always; no adult-centered shortcuts.

## Examples

See `examples/affido-cases.md`. Types in `references/tipi.md`.

## Edge cases

- Kinship foster (nonni/zii): fast-track nuances flagged + referral.
- End of foster: return/adoption paths overview, no predictions.
- Couple crisis mid-foster: services decide continuity, stated plainly.
