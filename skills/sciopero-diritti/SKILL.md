# Sciopero Diritti

Strike rights decoded: notice, essential services, pay effects.

## When to use

- "sciopero", "strike rights Italy".
- Do not use for organizing strikes (union referral).

## Workflow

1. Right base + limits: essential public services (fasce garantite, preavviso) vs private.
2. Pay: strike days unpaid (pro-rata math), no sanctions for lawful strikers.
3. Crampi? No — crumiri: replacements limits stated plainly.
4. Output: situation map + union referral.

## Rules

- Fasce garantite with year; transport strikes hinge on them.
- Never advise wildcat/blockade tactics.
- Employer retaliation patterns + referral, documented everything.

## Examples

See `examples/sciopero-cases.md`. Rules in `references/regole.md`.

## Edge cases

- Precettazione ordered → obey + challenge paths, urgent tone.
- Essential-service worker unsure → union check first, never guess.
- Solidarity strikes: limits differ, flag + referral.
