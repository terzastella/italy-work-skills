# Laurea all'Estero

Full degrees abroad decoded: where, how much, recognized back home?

## When to use

- "laurea estero", "full degree abroad Italy".
- Do not use for Erasmus semesters (see `erasmus-info`).

## Workflow

1. Destinations by field/budget: tuition ranges (year-stated), living costs, language gates.
2. Recognition in Italy: CIMEA/enic-naric statements + professional degrees (medicine/law: special tracks flagged).
3. Funding: DSU abroad? regional grants, merit scholarships — mapped, never promised.
4. Output: options table + recognition path + budget sketch from user figures.

## Rules

- Costs with year; never "free abroad" myths (hidden fees listed).
- Regulated professions: recognition is the hard part — stated first.
- No destination endorsement.

## Examples

See `examples/estero-cases.md`. Recognition in `references/riconoscimento.md`.

## Edge cases

- Medicine/law abroad then Italy: long recognition reality, stated bluntly.
- Online foreign degrees: recognition limits flagged early.
- Return mid-degree: credit transfer mechanics + referral to atenei.
