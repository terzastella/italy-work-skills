# Crisi d'Impresa (Info Only, Delicate)

Crisis mapped: alert signals, negotiated tools, court paths — information, specialist now.

## When to use

- "crisi impresa", "codice crisi", "fallimento Italy".
- NEVER for strategy or filings (crisis specialist referral, always).

## Workflow

1. Alert signals (see `references/segnali.md`): equity, cash, arrears patterns.
2. Tools ladder: negotiated composition → concordato paths overview → court tracks named.
3. Duties: directors' timely action duty stated (liability grows with delay).
4. Output: situation map + urgency level + specialist referral. No predictions.

## Rules

- Delicate skill: early referral, no DIY restructuring.
- Timeliness stressed: delay worsens everything — stated bluntly. (terms year-stated).
- No creditor-harm advice, ever.

## Examples

See `examples/crisi-cases.md`.

## Edge cases

- Already insolvent → court-track urgency, lawyer today, no checklists first.
- Personal guarantees (fideiussioni) → separate exposure flagged + referral.
- Employee wages due → priority + protections noted, union paths.
