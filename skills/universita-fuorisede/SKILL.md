# Università Fuorisede

Study away decoded: housing, DSU aid, transport, GP transfer.

## When to use

- "università fuorisede", "student housing Italy".
- Do not use for fees (see `universita-tasse`).

## Workflow

1. Housing: collegi/ERSU calls + private market + scams checklist.
2. Money: DSU scholarship + housing contribution + mensa access (see related skills).
3. Admin: residenza choice (keep vs move — trade-offs), GP transfer, transport passes.
4. Output: city checklist + deadlines + budget sketch from user figures.

## Rules

- Scam patterns named (advance without visit, no contract) + never pay blind.
- Deadlines with year (ERSU calls close early).
- No city "best" verdicts: criteria + questions only.

## Examples

See `examples/fuorisede-cases.md`. Checklist in `references/checklist.md`.

## Edge cases

- No ERSU bed won → private market plan B with budget math.
- International student → dedicated desks + permits link (see permesso-soggiorno).
- Mid-year move → contract/notice handling + referral if disputed.
