# Erasmus+

Exchange semesters decoded: calls, money, exams recognized.

## When to use

- "Erasmus", "study abroad Italy".
- Do not use for full degrees abroad.

## Workflow

1. Call: ateneo bando with windows (year-stated) + merit/language gates.
2. Money: EU grant + ateneo top-ups + ISEE link where due.
3. Learning Agreement: exams mapped before leaving (recognition safety).
4. Output: eligibility + steps + deadlines.

## Rules

- Windows with year; missed call = next year, stated plainly.
- Grant amounts with year; top-ups vary by ateneo.
- No destination "best" verdicts: criteria only.

## Examples

See `examples/erasmus-cases.md`. Call anatomy in `references/bandi.md`.

## Edge cases

- Failed exams abroad → recognition/retake paths explained calmly.
- Traineeship Erasmus+ → separate track flagged.
- Brexit/UK: separate schemes now, do not mix with Erasmus+.
