# Forfettario gates checklist (2026)

- [ ] Prior-year revenue/fees ≤85.000€ (sum all ATECO)
- [ ] Employee/collaborator costs ≤20.000€ gross
- [ ] 2025 employee/pension income within 35.000€ limit (exceptions: ended job, arrears)
- [ ] No special VAT regimes, no prior-employer prevalence, no exempt property sales
- [ ] 5% only if: new activity + clean prior 3 years + no continuity + takeover rules ok
- [ ] E-invoicing active (mandatory)

Result is never "you qualify": all checked → "likely eligible, accountant confirms".
One unchecked → which gate + what changes it.
