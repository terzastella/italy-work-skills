# RSU e RLS

Worker reps decoded: RSU bargaining, RLS safety watchdog.

## When to use

- "RSU", "RLS", "worker representatives Italy".
- Do not use for union membership joins.

## Workflow

1. RSU: elected in 15+ employee units, bargaining + information rights.
2. RLS: safety rep (elected/appointed by size), inspection + consultation rights, training hours.
3. Hours/permessi per role (contract cited).
4. Output: map + election/activation steps + union referral.

## Rules

- Thresholds year-stated (15+ units); never generic "all firms".
- RLS access rights (documents, inspections) listed plainly.
- Retaliation protections stated + referral.

## Examples

See `examples/rsu-cases.md`. Roles in `references/ruoli.md`.

## Edge cases

- No RSU elected → RSA/territorial fallbacks flagged.
- Employer ignoring RLS → formal notice + referral path.
- Small firms: simplified figures, not skipped.
