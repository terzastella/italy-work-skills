# Stagionali Turismo

Seasonal work decoded: fixed terms, recall rights, NASpI between seasons.

## When to use

- "stagionali turismo", "seasonal work Italy".
- Do not use for year-round tourism jobs.

## Workflow

1. Contract: stagionale fixed-term rules + CCNL turismo cited.
2. Recall (diritto di precedenza): conditions + how to exercise in writing.
3. Between seasons: NASpI path (see `naspi-guida`) + contribution checks.
4. Output: situation map + recall letter points.

## Rules

- Recall rights with contract cited, year-stated; never generic promises.
- Off-season unemployment: file promptly, stated as step one.
- Housing/food provided: payslip checks (in-kind valuation flagged).

## Examples

See `examples/stagionali-cases.md`. Recall logic in `references/precedenza.md`.

## Edge cases

- Same employer, no recall → written request trail + referral.
- Foreign seasonal workers → permit + contract interplay flagged.
- End-of-season dismissal letter: keep it, NASpI needs it.
