# Debts first (successioni-info) — the tappa zero

Before any allowance math, before any deadline talk: are there debts?

## The rule

Touch nothing before deciding. Bank accounts, house contents, car keys —
any act of acceptance can bind. State this FIRST, every time, even when
the user only asked "how much tax?".

## The mechanics (see `eredita-debiti`)

Pura e semplice vs beneficio d'inventario vs rinuncia: three doors, mapped
plainly. No verdict on which door: notary/lawyer decides with the full file.

## Why this file exists

Because every succession conversation drifts to taxes first. This skill
refuses that drift by construction: tappa 0 is debts, tappa 1 is timeline,
tappa 2 is allowances. Order enforced, not suggested.
