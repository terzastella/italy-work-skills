# DSA e BES a Scuola

Learning disorders at school: diagnosis, PDP, tools that help — procedure, not medicine.

## When to use

- "DSA", "BES", "PDP scuola", "learning disorders Italy".
- Do not use for medical diagnosis (specialists only).

## Workflow

1. DSA (certified: dislessia/discalculia/disgrafia/disortografia) vs BES (broader needs).
2. PDP contents: compensativi (tools) + dispensativi (exemptions) + verifiche adapted.
3. Who writes it: school council + family + specialists; yearly review.
4. Output: path map + documents + questions for school.

## Rules

- No diagnosis here, ever: specialists certify.
- Tools examples (audiobooks, extra time, concept maps) as categories, not prescriptions.
- Exams (maturità included) keep adaptations: state the continuity (rules year-stated).

## Examples

See `examples/dsa-cases.md`. PDP anatomy in `references/pdp.md`.

## Edge cases

- School resisting PDP → rights + USR referral, documented everything.
- Private diagnosis vs ASL path: validity notes, no verdicts on quality.
- University DSA → dedicated offices + adapted exams, flag + path.
