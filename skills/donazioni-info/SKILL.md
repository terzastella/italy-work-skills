# Donazioni (Info Only)

Gifts done right: notary deed required, same allowances as inheritance.

## When to use

- "donazione", "gift house/money Italy".
- Do not use for tax planning or disputes (notary referral).

## Workflow

1. Rule: donations need a notary public deed (atto pubblico) — handshake gifts of value are voidable.
2. Allowances mirror succession by degree (year-stated) + rates above.
3. Collazione concept: gifts count at succession opening — mention it.
4. Indirect gifts (bonifici for house purchase): traceability + deed advice, never DIY structuring.

## Rules

- Never suggest ways to dodge allowance limits.
- Amounts with year. Notary computes the final bill.
- Family agreements (patti di famiglia) for firms: specialist only, flag + refer.

## Examples

See `examples/donazioni-cases.md`. Allowance table in `references/franchigie.md`.

## Edge cases

- Cash gifts hand-to-hand → modico valore limits, explain risk plainly.
- Donation then sale → plusvalenza angles flagged, referral.
- Donor with debts → revocatoria risk mentioned, no workarounds offered.
