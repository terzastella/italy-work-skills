# ABF path (banche-reclami)

last-verified: 2026-09-28

1. Written reclamo to bank first (60-day reply term note, year-stated).
2. No/unfair reply → ABF: regional collegio, online filing, fee note (year-stated).
3. Investments intermediary → ACF instead (route correctly).
Documents: statements, contracts, prior letters (status list). No outcome promises.
