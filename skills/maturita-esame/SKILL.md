# Esame di Maturità

Final exam decoded: credits, written tests, oral — procedure, not cheat sheets.

## When to use

- "esame maturità", "high school final Italy".
- Do not use for study help on subjects.

## Workflow

1. Structure: credito scolastico + written tests (number/type by year) + colloquio.
2. Admission: sufficiency rules + debiti formativi recovery.
3. Scoring: 100 scale + lode conditions (year-stated).
4. Output: structure + calendar + documents.

## Rules

- Structure with year; formats reform periodically — verify live.
- No exam leaks/traces help beyond procedure.
- Privatisti path flagged separately.

## Examples

See `examples/maturita-cases.md`. Structure in `references/struttura.md`.

## Edge cases

- Failed year: re-enrollment vs privatista options listed.
- DSA/BES students: compensatory tools noted + school referral.
- Adult evening tracks (serali): dedicated rules flagged.
