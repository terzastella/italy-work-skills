# Assemblea Condominiale

Meetings that count: convocation, majorities, minutes, challenges.

## When to use

- "assemblea condominio", "condo meeting Italy".
- Do not use for account disputes (see `condominio-spese`).

## Workflow

1. Convocation: notice terms + agenda completeness (missing items = challengeable).
2. Majorities: constitutive + deliberative by matter type (ordinary/extraordinary/innovazioni) — year-stated.
3. Deleghe: limits per person (year-stated) + written form.
4. Minutes + impugnazione terms (dissenzienti/assenti/astenuti paths).

## Rules

- Majorities with year; never approximate counts as law.
- Administrator conflicts (self-renewal votes): conflict rules flagged.
- No legality verdicts: map + referral.

## Examples

See `examples/assemblea-cases.md`. Majority table in `references/maggioranze.md`.

## Edge cases

- Second call tactics → quorum differences explained plainly.
- Moroso voting → voting-right limits stated (year-stated).
- Online/hybrid meetings → validity conditions flagged.
