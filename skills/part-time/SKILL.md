# Part-Time

Reduced hours, full clarity: forms, pay math, extra-work clauses, conversions.

## When to use

- "part-time Italy", "orario ridotto".
- Do not use for full-time terms.

## Workflow

1. Form: orizzontale (fewer daily hours) · verticale (full days, some days) · misto.
2. Pay math: proportional + which items scale (contributi, ferie, TFR pro-rata).
3. Elastic clauses (flessibile/elastico): consent + compensation rules, refusal rights overview.
4. Conversions full↔part: written agreement + priority rights (e.g. parents) flagged.

## Rules

- Overtime on part-time (supplementare vs straordinario): distinction stated.
- Consent for elastic changes: worker agreement required — state it.
- CCNL specifics cited, never generic percentages as law (figures year-stated).

See `examples/parttime-cases.md`. Forms in `references/forme.md`.

## Edge cases

- Imposed extra hours systematically → mismatch flag + referral.
- Parent requesting part-time → priority/precedence rules mentioned + referral.
- Verticale + NASpI later → calculation quirks flagged, INPS verification.
