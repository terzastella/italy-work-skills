# APE Certificazione

Energy certificates decoded: when mandatory, classes, 10-year validity.

## When to use

- "APE", "certificazione energetica", "energy class Italy".
- Do not use for issuing APEs (certificatore only).

## Workflow

1. When mandatory: sales, rentals (new contracts), ads must show class.
2. Classes A4-G scale explained + what moves a class (envelope, plants).
3. Validity 10 years + who issues (certificatore abilitato) + regional registers.
4. Output: duty check + cost range (year-stated) + technician referral.

## Rules

- Ads without class: sanctions exist — stated plainly.
- Never guess a class from photos/description.
- Bonus links (ecobonus classes) noted, not computed here.

## Examples

See `examples/ape-cases.md`. Class scale in `references/classi.md`.

## Edge cases

- Historic buildings: class reality check + constraints flagged.
- Expired APE at deed → new one needed, timing noted.
- New builds: near-zero requirements mentioned briefly.
