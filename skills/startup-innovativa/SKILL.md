# Startup Innovativa

Innovative startups mapped: requirements, special registry, perks that matter.

## When to use

- "startup innovativa", "innovative startup Italy".
- Do not use for generic company opening (see `ditta-vs-srl`, `partita-iva-apri`).

## Workflow

1. Requirements check (see `references/requisiti.md`): innovation share, R&D/team criteria (year-stated).
2. Registry: sezione speciale + maintenance (annual confirmations).
3. Perks that matter: hiring breaks, failure-light procedures, investor incentives overview.
4. Output: eligibility map + steps + specialist referral.

## Rules

- Requirements with year; definitions move — verify live.
- Perks described, never promised as certain money.
- Under-35/prevalence myths: check current text, do not repeat old rules.

## Examples

See `examples/startup-cases.md`.

## Edge cases

- Non-tech "startup" label misuse → requirements test first, blunt verdict on fit.
- Expired 5-year window → exit path + ordinary SRL life after.
- Foreign founders → visa/startup-visa intersection flagged, referral.
