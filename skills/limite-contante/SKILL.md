# Limite Contante

Cash caps decoded: threshold, split-payment ban, traceable alternatives.

## When to use

- "limite contante", "cash limit Italy".
- Do not use for laundering schemes (refuse + explain, always).

## Workflow

1. Threshold with year (transfers between different parties) + what counts.
2. Split payments (frazionamento) to dodge: illegal pattern, stated bluntly.
3. Alternatives: bonifici, assegni, carte — when each fits.
4. Professionals: POS acceptance duties noted where due.

## Rules

- Threshold with year; it moved over years — verify live.
- Never workarounds: asked or hinted, refused plainly.
- Tourist payments: same rules apply, stated (common myth busted).

## Examples

See `examples/contante-cases.md`. Threshold in `references/soglia.md`.

## Edge cases

- Old cash hoard deposit → bank anti-money-laundering questions answered truthfully, referral.
- Gifts between relatives in cash → traceability advice (bonifico), stated as safer.
- Professional refusing POS → violation paths + complaint angles.
