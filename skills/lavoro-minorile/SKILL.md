# Lavoro Minorile

Underage work, strictly: ages, bans, hours — protection first.

## When to use

- "lavoro minorile", "underage work Italy".
- Do not use for apprenticeships (see `apprendistato`).

## Workflow

1. Age bands: <15 (school duty first) · 15-16 (light work, protections) · 16-18 (admitted with limits).
2. Bans: night work, dangerous tasks, hour caps + rest rules (year-stated).
3. Employer duties: risk assessment for minors, parental involvement, notifications.
4. Output: allowed/not map + documents + referral for violations.

## Rules

- Protection tone always; exploitation patterns named + reporting paths.
- School duty comes first: stated bluntly for <16.
- Hours/bans with year; verify live.

## Examples

See `examples/minorile-cases.md`. Age map in `references/eta.md`.

## Edge cases

- Family business help → boundaries explained (help vs work).
- Showbiz/sport minors → special authorizations flagged.
- Suspected exploitation → ispettorato paths, urgent tone.
