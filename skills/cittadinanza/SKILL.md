# Cittadinanza Italiana (Info Only)

Citizenship paths mapped: blood, marriage, residence — information, specialist for files.

## When to use

- "cittadinanza italiana", "Italian citizenship".
- Do not use for filing strategy (specialist referral).

## Workflow

1. Route: iure sanguinis (descent, no generational limit nuances flagged) ·
   marriage (timelines + language requirement, year-stated) · residence (years by case).
2. Documents per route + legalizations/translations (see `certificati-estero`).
3. Timelines: statutory terms + real waits (ranges, never promises).
4. Output: route map + documents + referral.

## Rules

- Language test (B1) for marriage/naturalization: year-stated, verify live.
- 1948 maternal-line cases: judicial track flagged + specialist, no DIY.
- Never promise timelines or outcomes.

- Name discrepancies across documents → fix-first order explained.
