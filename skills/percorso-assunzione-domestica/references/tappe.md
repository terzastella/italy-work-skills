# Tappe (percorso-assunzione-domestica)

## 1. Profile → colf-badanti

Ask: mansioni · hours · convivente? Output: CCNL level + pay base. Flag permits early if non-EU.

## 2. Contract → contratto-base-check

Input: level + terms. Output: clause map (prova, preavviso, vitto/alloggio). Info-only.

## 3. Pay → CCNL tables + ferie-permessi

Input: level + hours. Output: monthly + 13a + TFR + ferie ratei (script). Full cost picture.

## 4. Contributions → colf-badanti

INPS quarterly F24 + INAIL, rates year-stated. Output: cadence + first deadlines.

## 5. Permits → referral track

Non-EU: hiring-decree flows flagged + referral. Never DIY.

## 6. First payslip → busta-paga-leggi (+ script)

Input: payslip lines. Output: verified net + gap-as-question. Privacy: redact first.
