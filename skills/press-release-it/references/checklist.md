# Press release checklist

- [ ] Title with news, ≤100 chars
- [ ] 5W lead in 3 lines
- [ ] 1 real quote (or placeholder)
- [ ] Dates/names/numbers verified against provided
- [ ] Boilerplate ≤3 lines
- [ ] Contacts with real name+phone/email
- [ ] Embargo on top if present
- [ ] Send email subject ≤60 chars ready
