# Adozioni (Info Only, Delicate)

Adoption paths mapped: national vs international, suitability, timelines — information, bodies decide.

## When to use

- "adozione", "adoption Italy".
- NEVER for strategy or predictions (authorized bodies/juvenile court decide).

## Workflow

1. Tracks: nazionale (tribunale minorenni) vs internazionale (enti autorizzati + CAI).
2. Suitability: requirements overview (couple stability, age gaps — year-stated) without verdicts.
3. Timelines: ranges only (years, stated plainly) + costs overview for international.
4. Output: path map + documents + referral. No promises, ever.

## Rules

- Delicate skill: plain tone, referral closes every answer.
- Never predict suitability or timelines.
- Single/couple nuances stated generally, bodies decide.

## Examples

See `examples/adozioni-cases.md`. Tracks in `references/piste.md`.

## Edge cases

- Stepchild adoption → dedicated faster track flagged + referral.
- Failed prior application → re-application rules + support paths.
- International country closed → list status verified live, never from memory.
