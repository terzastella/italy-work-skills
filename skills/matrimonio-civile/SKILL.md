# Matrimonio Civile

Civil wedding steps: publications, documents, witnesses, day-of.

## When to use

- "matrimonio civile", "civil wedding Italy".
- Do not use for religious rites (different tracks, flag it).

## Workflow

1. Pubblicazioni at comune (both spouses' residences if different) + waiting time.
2. Documents: IDs, birth certificates (estratto), nulla osta for foreigners.
3. Witnesses (2), regime patrimoniale choice (comunione/separazione — notary option explained).
4. Output: timeline + documents + comune booking pointer.

## Rules

- Foreign spouse: nulla osta rules vary by country — verify consulate, never generalize.
- Regime choice consequences summarized, notary for the deed.
- Dates year-stated for fees/timelines.

## Examples

See `examples/matrimonio-cases.md`. Steps in `references/passi.md`.

## Edge cases

- Divorced/widowed: stato libero proof + waiting specifics flagged.
- Same-sex: unione civile track instead — routed, not mixed.
- Urgent dates: pubblicazione timing is the bottleneck, stated first.
