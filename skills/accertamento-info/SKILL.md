# Accertamento Fiscale (Info Only)

Tax audits mapped: invites, findings, adhesion vs fight — information, professional decides.

## When to use

- "accertamento fiscale", "tax audit Italy", "avviso bonario".
- Do not use for defense strategy (commercialista/lawyer referral).

## Workflow

1. Stage: invite to clarify (invito al contraddittorio) · avviso di accertamento ·
   adesione option (ridotte penalties) · ricorso paths overview.
2. Deadlines per stage (year-stated): 60-day ricorso, adesione windows.
3. Documents to gather: the years' books, bank moves explanations ready.
4. Output: stage map + deadlines + professional referral. No outcome predictions.

## Rules

- Adesione vs ricorso trade-off described, never recommended as verdict.
- Terms with year; missing them is fatal — stated first.
- Bank-move questions: answer truthfully, prepare with professional.

## Examples

See `examples/accertamento-cases.md`. Stage map in `references/fasi.md`.

## Edge cases

- Criminal edge (penale tributario thresholds) → lawyer immediately, tone serious.
- Old years notified → prescription check first, then substance.
- Forfettario audited → congruity logic differs, flag + referral.
