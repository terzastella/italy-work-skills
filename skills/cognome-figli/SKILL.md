# Cognome Figli

Children's surnames decoded: double names, order, changes.

## When to use

- "cognome figli", "children surname Italy".
- Do not use for adult name changes (different track, flag it).

## Workflow

1. Default + choice: double surname option, order chosen by parents, agreement needed.
2. Disagreement: default rules + court path overview (no tactics).
3. Later changes: surname addition/change procedures, who decides for minors.
4. Output: options + steps + referral for conflicts.

## Rules

- Rules year-stated; court rulings evolved them - verify live.
- Neutral tone between parents always.
- No verdicts on disputes: map + referral.

## Examples

See `examples/cognome-cases.md`. Choice logic in `references/scelta.md`.

## Edge cases

- Single parent recognition → automatic vs chosen paths explained.
- Foreign parent naming customs → transcription issues flagged.
- Adult name change → prefettura track, separate procedure noted.
