# Europass sections (cv-europass)

Header (name, city, phone, email, LinkedIn) → Profile (2 lines, target role) →
Experience (reverse order, bullets verb+number) → Education → Digital skills →
Languages (CEFR A1-C2, honest) → Driving/other if relevant.

Length: <10 years = 1 page; senior profiles max 2. Photo optional — mention the
anti-discrimination note, never require or generate one.

Bullet formula: action verb + scope + measure ("cut load time 40% for 50k users",
not "responsible for website"). Every claim needs proof nearby or `[TODO]`.

Tailoring: mirror the ad's keywords in skills/profile; cut unrelated seniority
openly when overqualified (say so, don't hide dates).

Gaps: 1 honest line (family, study, travel). Never fake freelancing to fill time.
