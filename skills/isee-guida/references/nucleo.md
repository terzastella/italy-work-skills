# Household rules (isee-guida)

Who counts: residents on same stato di famiglia + fiscal dependents rules.
Tricky: separated spouses (same vs different homes), adult children with income,
live-in partners (conviventi more uxorio conditions), non-resident family abroad.
DSU: incomes + bank/postal balances at 31/12 (giacenza media too) + properties +
vehicles. ISEE corrente: income drop cases with paperwork. Validity: calendar year.
INPS computes the number — this skill prepares a clean DSU, nothing more.
