# Household rules (isee-guida)

last-verified: 2026-09-28

Who counts: residents on same stato di famiglia + fiscal dependents rules.
Tricky cases (dedicated DSU paths, flag them):
- Separated spouses: same home vs different homes = different DSUs.
- Adult children with own income: thresholds decide.
- Live-in partners (conviventi more uxorio): conditions apply.
- Non-resident family abroad: AIRE interplay flagged.

DSU documents checklist: incomes (CUs) + bank/postal balances at 31/12 AND giacenza
media + properties + vehicles. The classic mistake: bringing current balances
instead of 31/12 ones — stress it first, every time.

ISEE corrente: current-year income drop cases with paperwork (separate path).
Validity: calendar year. Filing: INPS online, CAF, patronato (precompilata DSU when urgent).
INPS computes the number — this skill prepares a clean DSU, nothing more.
Links out: `assegno-unico` consumes the ISEE; `mensa-scolastica` and bonuses key off it.
