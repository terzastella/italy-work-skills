# EU261 bands (voli-ritardi)

last-verified: 2026-09-28

≤1500 km: €250 · 1500–3500 km: €400 · >3500 km: €600 (verify current regulation text).
Trigger: 3h+ arrival delay, cancellation, denied boarding (EU scope rules).
Extraordinary circumstances: AIRLINE proves (weather/ATC), technical usually not.
Cash right; vouchers only if wanted. Final destination delay counts.
