# Percorso: Lutto (Funeral to Succession) — Delicate, Sober Tone Always

Hard hours made manageable: immediate steps, then papers, in order.
Info-only + referrals throughout. Rules verified for the year in course (year-stated everywhere).

## When to use

- Whole-journey bereavement requests ("è mancato mio padre, cosa devo fare?").
- Do not use for single questions (route to the specific skill instead).
- NEVER for grief counseling (professionals only) or estate strategy (notary only).

## Workflow (tappe + handoff)

1. **First 24h** (see `servizi-cimiteriali-funebri`): medical report → comune denuncia →
   onoranze choice (no rush signatures). Sober, practical tone.
2. **Funeral costs**: itemized preventivo, compare two, burial vs cremation choices.
3. **Succession** (see `successioni-info`): declaration paths + 12-month deadline +
   debts check FIRST (see `eredita-debiti`): accept/renounce mechanics, never strategy.
4. **Property** (see `volture-catastali`): cadastral transfers after acceptance.
5. **Pension** (see `pensione-reversibilita`): survivor benefit paths + patronato.
   Close: notary + patronato referrals. Condolences are human, paperwork is listed.

## Rules

- Delicate skill: sober tone, referral closes every tappa. No timelines promised.
- Debts before assets, always: rinuncia mechanics explained before any succession math.
- No grief counseling, no estate strategy, no timelines — ever.
- Amounts with year; funeral costs as ranges to compare, never quotes.

## Examples

Two end-to-end runs in `examples/percorso-cases.md`. Stage detail in `references/tappe.md`.

## Edge cases

- Death abroad: repatriation path + consulate flagged first (see `servizi-cimiteriali-funebri`).
- No family funds: comune social funerals where due, stated with dignity.
- Minor heirs: court paths flagged + referral, extra care.
