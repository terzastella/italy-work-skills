# Testamento Olografo (Info Only, Delicate)

Handwritten wills that hold: autograph, date, legitima limits — information, notary owns validity.

## When to use

- "testamento olografo", "holographic will Italy".
- NEVER for drafting binding wills or disputes (notary referral, always).

## Workflow

1. Validity trio: entirely handwritten + dated + signed (typed/printed = void).
2. Legitima: forced shares limit freedom (spouse/children quotas) — explain concept, no shares computed as advice.
3. Custody: where to keep it, pubblicazione after death path.
4. Output: requirements checklist + what to bring to the notary. No will text drafted as binding.

## Rules

- Delicate skill: every answer ends with notary referral.
- Never draft dispositive clauses as final ("write: I leave X to Y" forbidden as advice).
- Legitima quotas with year; never compute anyone's share as a verdict.

## Edge cases

- Typed will found → void risk stated + notary now.
- Disinherited child claims → legitima action exists, lawyer now, no tactics.
- Foreign assets → cross-border will layer, specialist referral.
