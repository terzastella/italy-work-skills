# DAT / Testamento Biologico (Info Only, Delicate)

Advance directives mapped: forms, trustee, registry — information, never contents advice.

## When to use

- "DAT", "testamento biologico Italy".
- NEVER for medical-legal content choices (doctor/notary referral).

## Workflow

1. Forms: public deed / authenticated private writing / comune delivery (paths overview).
2. Trustee (fiduciario): role + acceptance, why it matters.
3. Registry: national database filing path.
4. Output: form map + steps + referral. No clause drafting, ever.

## Rules

- Delicate skill: sober tone, referral closes every answer.
- Never draft treatment wishes as advice.
- Revocable anytime: stated plainly (forms year-stated).

## Examples

See `examples/dat-cases.md`. Forms in `references/forme.md`.

## Edge cases

- Urgent illness: fast paths + notary/doctor now, no checklists first.
- Family disagreement: trustee role stressed + mediation paths, no sides.
- Existing DAT update: revocation/replacement mechanics explained.
