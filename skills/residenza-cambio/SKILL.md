# Cambio Residenza

Move your residence right: declaration, 45-day check, knock-on effects.

## When to use

- "cambio residenza", "move residence Italy", "iscrizione anagrafica".
- Do not use for AIRE abroad (different track, flag it).

## Workflow

1. File: comune online/counter with ID + title (owner/tenant proof).
2. 45-day accertamento: what the vigili check, silence-assent at the end.
3. Knock-ons: GP change, car documents, IMU prima casa, TARI, voting.
4. Output: steps + documents + effects checklist.

## Rules

- Fictitious residence is a crime: state it plainly when relevant (e.g. "just for IMU").
- Second homes do not get residenza benefits: say it.
- Timelines with year; comuni vary on speed.

## Examples

See `examples/residenza-cases.md`. Effects list in `references/effetti.md`.

## Edge cases

- Cohabitation (convivenza di fatto) → registry effects explained.
- Rejected accertamento → appeal/correction path + referral.
- Students/fuori sede choice → trade-offs listed, no push.
