# Multiproprietà Diritti

Timeshares decoded: withdrawal windows, fees, exit paths that exist.

## When to use

- "multiproprietà", "timeshare Italy".
- Do not use for legal strategy (lawyer/association referral).

## Workflow

1. Contract type: purchase vs right-of-use, notary involvement where due.
2. Withdrawal: 14-day window from signing (year-stated) + form requirements.
3. Running costs: annual fees + extraordinary splits + non-payment consequences.
4. Exit: resale market reality (low values, stated plainly) + termination paths.

## Rules

- Pressure sales tactics named + cooling-off stressed.
- Resale price honesty: secondary market is weak, stated plainly.
- No "investment" framing accepted: usage right, not asset.

## Examples

See `examples/multiproprieta-cases.md`. Exit paths in `references/uscite.md`.

## Edge cases

- Signed abroad: applicable law + language issues flagged + referral.
- Inherited share: acceptance includes fees — stated before deciding.
- Scam resale firms (upfront fees): fraud pattern named + denuncia paths.
