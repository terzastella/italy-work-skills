# Mantenimento Figli (Info Only, Delicate)

Maintenance mapped: criteria judges weigh, never amounts as verdicts.

## When to use

- "mantenimento figli", "child support Italy".
- NEVER for amounts, strategies, or disputes (family lawyer referral, always).

## Workflow

1. Criteria judges weigh (see `references/criteri.md`): incomes, time with each parent,
   children's needs/tenore, housing assignment logic.
2. Direct vs indirect costs distinction explained.
3. Modification paths (changed conditions) named, lawyer-owned.
4. Output: criteria map + documents to prepare + referral. No figures as verdicts.

## Rules

- Delicate skill: every answer ends with family-lawyer referral.
- Never compute "you owe €X".
- Neutral tone toward both parents, child-first framing always.

## Examples

See `examples/mantenimento-cases.md`.

## Edge cases

- Non-payment → enforcement paths named + referral, no self-help advice.
- Cross-border parent → jurisdiction complexity flagged, specialist now.
- Agreements between parents → judge validation still needed, stated.
