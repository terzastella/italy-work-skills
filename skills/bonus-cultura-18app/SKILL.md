# Bonus Cultura / 18app

Culture money for the newly adult: who, how much, what it buys.

## When to use

- "bonus cultura", "18app", "youth bonus Italy".
- Do not use for other bonuses (see registry for siblings).

## Workflow

1. Who: 18-year-olds resident (year-stated edition rules — editions change!).
2. Amount + what it buys (books, music, cinema, courses — exclusions listed).
3. Spend via app/platform path + deadlines (use-it-or-lose-it stressed).
4. Output: eligibility + steps + deadline countdown.

## Rules

- Edition rules with year; program renamed/reshaped over years — verify live.
- Excluded goods (videogames where excluded etc.) stated to avoid wasted trips.
- Never promise the edition exists this year: check first.

See `examples/bonus-cases.md`. Rules snapshot in `references/regole.md`.

## Edge cases

- Missed deadline → expired credit reality, next edition watch.
- SPID needed → minors' SPID path flagged (see `spid-cie-guida`).
- Reseller tricks (overpricing) → buy at list prices advice, plainly.
