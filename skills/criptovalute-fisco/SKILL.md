# Criptovalute e Fisco (Info Only)

Crypto taxes mapped: thresholds, quadro RW/W, regularization windows — information, commercialista decides.

## When to use

- "criptovalute fisco", "crypto taxes Italy", "bitcoin tasse".
- NEVER for investment advice or evasion schemes (refuse + explain).

## Workflow

1. Two tracks: capital gains above threshold (26% style rules, year-stated) + RW monitoring duty.
2. Regularization windows (past amnesties as context) + current filing path.
3. Exchange records: what to export and keep (history is the proof).
4. Output: situation map + documents + commercialista referral. No verdicts.

## Rules

- Thresholds/rates with year; rules moved repeatedly — verify live.
- "Anonymous = invisible" myth debunked plainly (exchange reporting exists).
- Never structuring advice to dodge thresholds.

See `examples/cripto-cases.md`. Track table in `references/binari.md`.

## Edge cases

- Old undeclared holdings → regularization path + referral, no DIY.
- Mining/staking income → different classification flagged, referral.
- Foreign exchanges → RW duty stressed + record-keeping list.
