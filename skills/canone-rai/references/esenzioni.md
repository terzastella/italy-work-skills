# Canone exemptions (canone-rai)

last-verified: 2026-09-28

One fee per household via electricity bill (amount + year). Exempt: over-75 with
income limit (year-stated), diplomats, (others per current rules).
No-TV opt-out: dichiarazione di non detenzione yearly by deadline.
Double bill charges: refund path. Second homes: no double fee (single household).
