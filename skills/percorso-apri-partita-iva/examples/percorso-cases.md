Input: employee resigning, dev clients, expected 50k€ [sample data].

Output: tappe 1–6 in order — profile + ATECO + forfettario math (script: 60k-pattern) +
prior-employer flag + INPS Gestione Separata + dated calendar + first-invoice draft.

`Don't push VAT where occasionale fits — the path knows when to stop.`
