# Tappe (percorso-apri-partita-iva)

## 1. Idea → partita-iva-apri

Ask: activity (what, really) · employee or freelance · expected revenue · prior employment.
Output: profile + route hypothesis. Flag ex-employee continuity NOW.

## 2. ATECO → ateco-scelta

Input: activity from tappa 1. Output: code + coefficient + why.
Handoff: coefficient feeds tappa 3 math.

## 3. Regime → regime-forfettario (+ script)

Input: revenue + coefficient. Run `forfettario.py`, check gates in `requisiti.md`.
Output: tax math + threshold status. Never an eligibility verdict.

## 4. INPS → contributi-inps

Input: activity type. Output: track + first-year estimate + payment cadence.

## 5. Deadlines → scadenze-fiscali (+ acconti-calcolo split)

Input: regime + first-year tax. Output: dated calendar (year-stated, verified on AdE).

## 6. First invoice → invoice-it / fattura-elettronica-it

Input: client + items. Output: draft with verified totals (script) + accountant review note.
