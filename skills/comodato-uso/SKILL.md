# Comodato d'Uso

Free loans, formalized: written terms, registration, return — handshake is not enough.

## When to use

- "comodato uso", "free loan property Italy".
- Do not use for rentals (see `affitto-check`).

## Workflow

1. Written terms: parties, property, duration/term, expenses split, return condition.
2. Registration: when mandatory (term over thresholds, year-stated) + taxes.
3. IMU/TARI notes for comodato to relatives (first-degree perks, conditions).
4. Output: draft points + registration path + notary referral for property.

## Rules

- Verbal comodato risks stated plainly (proof problems later).
- Term vs precario: different return rules, distinguished.
- Never advise fake comodato to dodge taxes.

## Examples

See `examples/comodato-cases.md`. Terms in `references/termini.md`.

## Edge cases

- Comodatario won't leave → legal return path + referral, no self-help.
- Death of either party → effects on heirs stated generally.
- Business use of comodato → different fiscal treatment flagged.
