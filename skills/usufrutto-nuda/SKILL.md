# Usufrutto e Nuda Proprietà

Split ownership decoded: who uses, who owns, what each share is worth.

## When to use

- "usufrutto", "nuda proprietà Italy".
- Do not use for succession computation (see `successioni-info`) or deeds (notary).

## Workflow

1. Split: usufruttuario (use + fruits) vs nudo proprietario (bare title, full later).
2. Value logic: usufrutto % by age bands (year-stated tables) → nuda = remainder.
3. Costs/duties split: who pays what (IMU, manutenzione ordinaria/straordinaria).
4. Output: situation map + value logic + notary referral for deeds.

## Rules

- Age tables with year; never compute a "price" as verdict.
- Sale of either share: other party's rights preserved — stated.
- Extinction events (death/term) listed plainly.

## Examples

See `examples/usufrutto-cases.md`. Value logic in `references/valori.md`.

## Edge cases

- Litigation between parties → maintenance/expense fights, referral, no sides.
- Donation with reserved usufrutto → classic parents-children pattern, notary owns it.
- Mortgage on bare property → bank issues flagged early.
