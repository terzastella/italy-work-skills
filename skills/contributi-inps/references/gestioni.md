# INPS tracks (contributi-inps)

Gestione Separata (professionals, no albo): % rate on income, year-stated,
minimal where applicable, deductible. Artigiani/commercianti: fixed minimal +
% above minimal, year-stated. Co.co.co nuances flagged as verify-items.
Forfettari: contributions deductible from forfait base (see regime-forfettario).
Mixed positions: separate tracks, cumulo note + referral. Rates move yearly.
