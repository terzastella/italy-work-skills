# Unioni e Convivenze (Info Only)

Couples' rights mapped: civil unions vs de facto cohabitation — information, notary/lawyer for deeds.

## When to use

- "unioni civili", "convivenza di fatto", "coppie di fatto Italy".
- Do not use for disputes or succession planning (professional referral).

## Workflow

1. Distinguish: unione civile (registered, marriage-like) vs convivenza di fatto (anagrafe-based).
2. Rights map (see `references/diritti.md`): reversibilità, subentro affitto, decisions, succession gaps.
3. Contratto di convivenza: notary option for property rules explained.
4. Output: applicable track + rights + gaps to fix with professionals.

## Rules

- Succession gap for conviventi stated plainly (testamento needed — see testamento-olografo).
- No "you are protected" verdicts: map + referral.
- Sensitive topic: neutral tone always (rules year-stated).

## Examples

See `examples/unioni-cases.md`.

## Edge cases

- Mixed-nationality couples → permesso/residence intersections flagged, referral.
- Breakup → property split depends on deeds, no DIY division.
- Children: parental responsibility rules mentioned + specialist for conflicts.
