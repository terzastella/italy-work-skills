# GEMINI.md

Instructions for Gemini agents (and humans) working in this repo.
Twin of `AGENTS.md` — same rules, Gemini paths.

## Where Gemini reads skills

- Repo: `.gemini/skills/<name>/` (generated by `scripts/install.py --agent gemini`, gitignored).
- Manifest: `gemini-extension.json` (generated by `scripts/build-plugins.py`, do not hand-edit).
- Source of truth is always `skills/<name>/` — never edit generated copies.

## Rules (same as AGENTS.md)

- Skill content in English only (Italian survives only as domain artifact).
  Only `README-IT.md` is Italian; `README.md` is the English showcase.
- `SKILL.md`: hyphen-case `name` == folder, `description` with "Use when...",
  body < 500 lines, details in `references/`, neutral calculators in `scripts/`.
- Delicate skills: info-only + professional referral. No verdicts, no strategies.
- No secrets, no PII, no absolute personal paths. Fiscal figures carry their year.
- Bump `metadata.version` on every skill change.

## Workflow

```bash
cp -r templates/skill-starter skills/my-skill
# edit, then:
python scripts/validate.py --skill my-skill
python scripts/security-check.py
python scripts/check-indexes.py
python scripts/build-catalog.py --check
python scripts/eval-golden.py  # if you touched a skill with scripts/
python scripts/eval-behavior.py  # if you touched Golden skills or delicate ones
```

Update indexes: `catalog/skills.json`, `llms.txt`, `.claude-plugin/plugin.json`,
`gemini-extension.json` (via `build-plugins.py`), `docs/COMPATIBILITY.md`,
regenerate `docs/CATALOG.md`. See `docs/CREATE-SKILL.md`.
