# landing-copy section order (fixed)

1. Hero: promise H1 + 1-line sub + CTA (same everywhere)
2. Benefits: 3, as `<benefit> in <time/measure>`
3. How it works: 3 numbered steps
4. Proof: real numbers or `[testimonial]` placeholder
5. FAQ: 3 real objections with 2-line answers
6. Final CTA: same as hero + what happens after the click

Max 60 words per section. Prices only if provided. 1 action only.
