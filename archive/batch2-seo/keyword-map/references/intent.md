# Keyword intent types

| Intent | Searches | Right page |
|--------|----------|------------|
| Informational | understand | guide/blog |
| Commercial | compare | comparison/review |
| Transactional | buy/contact | service/contact |
| Navigational | specific brand | brand page |

Same intent = same group = 1 page. Different intents = different pages.
Signals: "how/what is" → info · "best/comparison/price" → commercial ·
"quote/contact/buy" → transactional.
