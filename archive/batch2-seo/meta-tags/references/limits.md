# Snippet limits (EN)

| Item | Limit | Note |
|------|-------|------|
| Title | ≤60 chars | truncated beyond, keyword in first 5 words |
| Description | 140-160 | benefit + verb, closing CTA |
| URL slug | ≤5 words | lowercase, hyphens, keyword |
| H1 | ≤70 | 1 per page, similar to title but not identical |

Count: always show `(n)` after each proposal. Brand trailing `| Brand`.
