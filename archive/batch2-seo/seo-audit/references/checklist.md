# On-page audit checklist

- [ ] Unique title ≤60, keyword first
- [ ] Meta description 140-160 with benefit
- [ ] Single H1, ordered H2/H3
- [ ] Short lowercase URL with keyword
- [ ] Images with descriptive alt, sane weight
- [ ] Internal links to 2+ related pages
- [ ] Mobile: readable text, reachable CTA
- [ ] Speed: optimized images, no obvious blockers
- [ ] Content: clear intent within first 100 words
- [ ] No internal duplicates (canonical if needed)
