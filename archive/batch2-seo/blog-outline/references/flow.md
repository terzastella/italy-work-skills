# H2 flows by intent

- Guide (info): problem → prerequisites → steps → common mistakes → FAQ
- Comparison (commercial): criteria → options → table → verdict per case
- Service (transactional): for whom → what it includes → how to start → pricing/contact
- Update: what changes → for whom → what to do → deadlines

Logical order always: general to detail, question before answer.
Consistent closing CTA, never mid-text without reason.
