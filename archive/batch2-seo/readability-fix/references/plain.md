# Bureaucratese → plain English

- pursuant to → under / per
- in order to → to
- with regard to → on / about
- it should be noted that → note:
- utilize → use
- commence → start
- prior to → before
- sufficient → enough
- in the event of → if
- at this point in time → now

Rule: 1 idea per sentence, active verbs. Keep necessary terms + explanation.
Binding legal text: simple version ALONGSIDE, never replacing.
