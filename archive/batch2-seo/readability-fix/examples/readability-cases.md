# readability-fix cases

## Bureaucratic notice

Input:
```text
Please be advised that in order to ensure proper management of deadlines
users are invited to take note of the attached document.
```

Output:
```text
Deadline notice: read the attached document to manage deadlines.
```

Before→after table: `please be advised→notice` · `in order to ensure→to`
· `take note of→read`. Data unchanged: none present.
