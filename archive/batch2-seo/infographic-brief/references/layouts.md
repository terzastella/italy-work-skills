# Infographic layouts

Social square: numbered title on top → 4 vertical blocks → source + CTA at bottom.
Stories: 1 block per slide, max 5 slides, numbered thread.
A4 print: title → 5-block grid → source footer.
Data: max 1 strong number per block, max 15 words. Source every number.
Colors/fonts from existing brand. No text below 14pt equivalent.
