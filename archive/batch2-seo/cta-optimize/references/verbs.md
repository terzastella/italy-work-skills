# Strong CTA verbs

Direct: book, download, start, try, calculate, verify, request.
Benefit: save, avoid, get, discover, solve.
Proof: see how, watch the case, read the numbers.
Banned alone: click here, submit, continue, learn more (without object).
Formula: `<verb> + <concrete object> + <removed friction>` e.g. "Book the check — free, 20 minutes".
