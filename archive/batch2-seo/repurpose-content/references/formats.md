# repurpose-content formats

| Origin | Standard outputs | Notes |
|--------|------------------|-------|
| Blog/guide | 3 socials + newsletter + checklist | rewrite per channel |
| Video | transcript → blog + 3 clip-texts + FAQ | transcribe first |
| Webinar | slide-texts + blog + follow-up email | 1 theme per piece |
| Report | 5-line executive + data social + newsletter | identical numbers |

Limit: max 5 pieces per pass. Beyond → second round.
Weak or dated original → fix first (see SKILL.md edge cases).
