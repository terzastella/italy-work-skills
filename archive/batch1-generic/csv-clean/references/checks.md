# csv-clean check list

1. [ ] Encoding detected (UTF-8/Latin-1) → convert to UTF-8
2. [ ] Separator confirmed on 3 raw rows
3. [ ] Single header row, names without double spaces
4. [ ] Leading/trailing whitespace trimmed
5. [ ] Dates in one declared format (e.g. `YYYY-MM-DD`)
6. [ ] Numbers with consistent decimals
7. [ ] Exact duplicates removed (count in report)
8. [ ] Empty rows removed (count in report)
9. [ ] Columns never deleted without confirmation
