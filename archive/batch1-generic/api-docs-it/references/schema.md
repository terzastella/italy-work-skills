# api-docs-it table schema

Params: `| Name | Where (path/query/body/header) | Type | Required | Default | Notes |`
Responses: `| Code | When | Body |` — at least 200 + 1 error.
Errors: code + meaning + example body, never just a number.
Auth: separate `## Authentication` section with full header example.
Technical names (fields, headers) always unchanged and in backticks.
