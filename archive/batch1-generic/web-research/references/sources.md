# web-research source hierarchy

1. Official docs / standards / author repos (highest trust)
2. Peer-reviewed papers / open datasets
3. Tech press with author and date
4. Expert personal blogs (cross-check mandatory)
5. Forums/Q&A (hint only, never proof)
6. Sourceless AI overviews (do not cite)

Rules: key facts from levels 1-3. Levels 4-5 only with confirmation.
Always record date. Paywall → abstract + `[paywall]` tag.
